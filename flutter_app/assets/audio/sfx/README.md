# Pixel Harmony sound effects

Place the licensed production sound-effect files in this directory using these
exact stems:

- `tile_pickup`
- `tile_swap`
- `level_complete`

Supported extensions are `.wav`, `.mp3`, `.m4a`, and `.aac`. Prefer short,
optimized `.wav` or `.mp3` files that have been tested on both Android and iOS.
No production audio assets are currently included.
